# WinX - Modern Quick Action Menu for Linux

WinX is a modern, beautifully designed shortcut menu inspired by the Windows `Win + X` menu, completely built for Linux. It works across X11 and Wayland on all major distributions.

## Features
- **Modern UI/UX**: Dark mode, rounded corners, frameless design.
- **Distro-Agnostic**: Uses standard Linux commands (`systemctl`, `loginctl`, `wpctl`) that work out of the box on Ubuntu, Fedora, Arch, etc.
- **Auto-Dismiss**: Disappears if you click away, press Esc, or press the Win key again.
